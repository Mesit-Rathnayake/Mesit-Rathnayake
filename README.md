# 🚀 Selected Work

> A few projects that represent the things I'm interested in building.

## 🎓 My Academia

**AI-powered academic management platform**

A student-focused platform for managing modules, grades, attendance, and academic progress.

Currently evolving toward an **AI-powered, citation-based academic assistant** capable of answering questions from university learning material using retrieval-augmented generation.

**Exploring:** `RAG` · `LLMs` · `Vector Search` · `AI Applications` · `Full-Stack`

**Built with:** `React` · `Node.js` · `MongoDB`

---

## 👁️ Hybrid Photo Enhancer

**Traditional image processing meets AI**

An experimental image-enhancement pipeline exploring how classical image-processing techniques can work alongside modern AI approaches.

The goal isn't just to make images look better — it's to understand **why different enhancement techniques work** and how they can be combined into practical pipelines.

**Exploring:** `Computer Vision` · `Image Processing` · `Machine Learning`

**Built with:** `Python` · `OpenCV` · `NumPy`

---

## 🏥 MOH Connect

**Healthcare management platform**

A full-stack platform designed to improve the management and communication of maternal and child healthcare information between healthcare workers and institutions.

Built with a focus on clean architecture, backend systems, database design, and future mobile integration.

**Exploring:** `Software Architecture` · `Backend Engineering` · `Cloud` · `CI/CD`

**Built with:** `React` · `Spring Boot` · `PostgreSQL` · `Docker`

---

## 💰 BudgetBuddy

**Personal finance + DevOps playground**

A personal finance application for tracking transactions, expenses, and spending habits.

More importantly, the project became a playground for learning how software moves beyond development into **automated deployment and infrastructure**.

**Exploring:** `Full-Stack` · `Docker` · `CI/CD` · `Infrastructure as Code`

**Built with:** `React` · `Node.js` · `MongoDB` · `Jenkins` · `Terraform` · `AWS`

---

## ⛓️ Toy Blockchain

# 🧠 How I Learn

I don't learn particularly well by just consuming tutorials.

My preferred loop is:

```text
Learn
  ↓
Build
  ↓
Break
  ↓
Debug
  ↓
Understand
  ↓
Build it better
```

That's why many of my projects start as experiments.

Sometimes the experiment becomes a real application.

Sometimes it becomes a broken repository.

Both are useful.
